Sistema de Gerenciamento Acadêmico Mostra+

Plataforma virtual para exibição e catalogação de projetos acadêmicos e universitários.

Descrição do Projeto

O Mostra+ é uma vitrine virtual desenvolvida para integrar alunos, professores e a comunidade acadêmica. O objetivo principal é catalogar projetos de extensão, trabalhos de conclusão de curso e pesquisas científicas de forma interativa e acessível.

A plataforma conta com sistema de busca inteligente, navegação por categorias, interface responsiva para dispositivos móveis e suporte a autenticação institucional via conta Microsoft (@ulife).
